## Code and tools

- [mcgill-smart-transport/population_synthesis_hierarchical](https://github.com/mcgill-smart-transport/population_synthesis_hierarchical): MATLAB code for Sun, Erath & Cai (2018), which gives an earlier github.com/lijunsun address. MIT.
- [zackAemmer/generative-population-synthesis](https://github.com/zackAemmer/generative-population-synthesis): Python notebooks for Aemmer & MacKenzie (2022), also in Aemmer, Z. (2021), *Generative Population Synthesis for Joint Household and Individual Characteristics* (Master's thesis, University of Washington). No license listed; link only.
- [HyunsooYun/llm-pop-synth](https://github.com/HyunsooYun/llm-pop-synth): Python notebooks for Lim et al. (2026), as printed in the paper. MIT.
- Jiang et al. (2022) code and data: [bit.ly/SynPopABM](https://bit.ly/SynPopABM) and [osf.io/3vsaj](https://osf.io/3vsaj/), as printed in the paper.
- [tkipf/gae](https://github.com/tkipf/gae): TensorFlow code for Kipf & Welling (2016). MIT.
- [AntonioLonga/PytorchGeometricTutorial](https://github.com/AntonioLonga/PytorchGeometricTutorial): PyTorch Geometric tutorials. No license listed; link only.
- [muhanzhang/SEAL](https://github.com/muhanzhang/SEAL): subgraph-based link prediction from Zhang, M., & Chen, Y. (2018), Link prediction based on graph neural networks, *NeurIPS 2018*, [arXiv:1802.09691](https://arxiv.org/abs/1802.09691). No license listed; link only.
- [JeffreyAlanSmith/ego_network_inference](https://github.com/JeffreyAlanSmith/ego_network_inference): R code for inference from ego-network data, with Smith, J. A., & Gauthier, G. R. (2020), Estimating contextual effects from ego network data, *Sociological Methodology*, 50, 215-275, [doi:10.1177/0081175020922879](https://doi.org/10.1177/0081175020922879). MIT.
- [CamDavidsonPilon/Probabilistic-Programming-and-Bayesian-Methods-for-Hackers](https://github.com/CamDavidsonPilon/Probabilistic-Programming-and-Bayesian-Methods-for-Hackers): notebooks for Davidson-Pilon, C. (2015), *Bayesian Methods for Hackers: Probabilistic Programming and Bayesian Inference*, Addison-Wesley. MIT.
- [jluttine/tikz-bayesnet](https://github.com/jluttine/tikz-bayesnet): TikZ library for Bayesian network diagrams. MIT.
